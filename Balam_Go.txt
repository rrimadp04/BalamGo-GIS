TAHAP 1	Download dan Install Semua Software

Tujuan
Menyiapkan seluruh perangkat lunak yang diperlukan sebelum memulai pengembangan. Semua software harus terinstall dengan benar agar proses selanjutnya berjalan lancar.

1.1 — Laragon
Apa itu Laragon?
Laragon adalah paket pengembangan web lokal untuk Windows yang menyertakan Apache, MySQL, PHP, dan Composer dalam satu instalasi. Laragon lebih ringan dari XAMPP dan sangat cocok untuk Laravel.

Langkah Download & Install:
1.	Buka browser dan kunjungi: https://laragon.org/download/
2.	Klik tombol "Download Laragon Full" (versi Full menyertakan PHP 8, MySQL, Apache, dll)
3.	Setelah file .exe selesai diunduh, double-click untuk menjalankan installer
4.	Pilih bahasa instalasi → klik OK
5.	Klik Next → pilih direktori instalasi (default: C:\laragon, JANGAN ubah path ini)
6.	Centang semua opsi → klik Install
7.	Tunggu proses instalasi selesai → klik Finish

Cara Menjalankan Laragon:
8.	Double-click ikon Laragon di desktop atau Start Menu
9.	Klik tombol "Start All" di panel Laragon untuk menjalankan Apache dan MySQL
10.	Pastikan indikator Apache dan MySQL berwarna HIJAU
11.	Buka browser → ketik http://localhost → halaman Laragon harus muncul

Cara Mengecek Apache dan MySQL Berjalan:
Klik kanan ikon Laragon di system tray → pilih "Apache" → pastikan ada tanda centang hijau. Lakukan hal sama untuk MySQL.

💡 Tips
Jika port 80 sudah dipakai aplikasi lain, klik kanan Laragon → Apache → Port → ubah ke 8080
Path default folder www: C:\laragon\www (ini tempat project Laravel akan dibuat)
Laragon otomatis membuat virtual host: http://balamgo.test jika folder project bernama balamgo

1.2 — Composer
Apa itu Composer?
Composer adalah package manager untuk PHP. Digunakan untuk menginstall Laravel dan semua dependency project. Laragon Full sudah menyertakan Composer, tapi pastikan terinstall dengan benar.

Cara Cek Composer:
Buka Command Prompt (CMD) atau Terminal Laragon, lalu jalankan:
composer -V
Hasil yang diharapkan:
Composer version 2.x.x  YYYY-MM-DD HH:MM:SS

Jika Composer tidak ditemukan, download manual dari https://getcomposer.org/Composer-Setup.exe → install → restart CMD.

1.3 — Visual Studio Code
Download & Install:
12.	Buka https://code.visualstudio.com
13.	Klik "Download for Windows" → jalankan installer .exe
14.	Saat instalasi, centang: "Add to PATH" dan "Open with Code" (penting!)
15.	Selesai install → buka VS Code

Extension yang Wajib Dipasang:
Buka VS Code → tekan Ctrl+Shift+X → cari dan install extension berikut:
Nama Extension	Kegunaan
PHP Intelephense	Autocomplete dan syntax highlighting PHP
Laravel Blade Snippets	Snippet cepat untuk template Blade Laravel
Laravel Extra Intellisense	Autocomplete routes, views, models Laravel
DotENV	Syntax highlighting file .env
Prettier - Code Formatter	Format otomatis kode HTML, CSS, JS

💡 Cara Install Extension
1. Tekan Ctrl+Shift+X di VS Code
2. Ketik nama extension di kotak pencarian
3. Klik install pada extension yang tepat
4. Setelah semua terinstall, restart VS Code

1.4 — QGIS
Download & Install:
16.	Buka https://qgis.org/en/site/forusers/download.html
17.	Klik "QGIS Standalone Installer Version (recommended for most users)"
18.	Download versi Windows 64-bit (.msi)
19.	Jalankan installer → klik Next terus → Finish
20.	Buka QGIS dari Start Menu atau Desktop

Membuka Project Baru di QGIS:
21.	Buka QGIS → klik menu Project → New
22.	Simpan project: Project → Save As → beri nama "balamgo_gis" → pilih folder kerja
23.	Pastikan Coordinate Reference System (CRS) diset ke WGS 84 (EPSG:4326)
24.	Cara set CRS: klik ikon bola di pojok kanan bawah → cari "EPSG:4326" → Apply

⚠️ Troubleshooting Tahap 1
Error: "composer" is not recognized → Pastikan Composer sudah terinstall dan PATH sudah ditambahkan. Restart CMD setelah install.
Error: Laragon tidak bisa start Apache → Port 80 mungkin dipakai oleh Skype/IIS. Klik kanan Laragon → Apache → Port → ganti ke 8080
QGIS crash saat dibuka → Update driver GPU atau tambahkan opsi --nologo di shortcut QGIS
VS Code tidak bisa mendeteksi PHP → Install PHP Intelephense dan atur php.executablePath di settings.json

3.8 — Membuat Buffer 2 km
Buffer digunakan untuk mengetahui wisata yang berada dalam radius 2 km dari fasilitas mitigasi.
81.	Klik menu Vector → Geoprocessing Tools → Buffer
82.	Input layer: pilih layer mitigasi
83.	Distance: 2000 (dalam meter, pastikan CRS layer adalah meter atau gunakan EPSG:32748 untuk UTM)
⚠️ Perhatian CRS untuk Buffer
Jika layer CRS adalah EPSG:4326 (derajat), jarak buffer harus dalam derajat (2 km ≈ 0.018 derajat)
Untuk buffer yang akurat, reproyeksikan layer ke EPSG:32748 (UTM Zone 48S) terlebih dahulu:
Vector → Data Management Tools → Reproject Layer → CRS: EPSG:32748
Lakukan buffer pada layer yang sudah diproyeksikan dengan jarak 2000 (meter)
Setelah selesai, reproyeksikan hasil buffer kembali ke EPSG:4326
84.	Centang "Dissolve result"
85.	Output: simpan sebagai "buffer_mitigasi_2km"
86.	Klik Run → hasil buffer akan muncul sebagai layer baru

TAHAP 6	Membuat Migration

Tujuan
Migration adalah file PHP yang mendefinisikan struktur tabel database. Dengan migration, struktur tabel bisa dibuat ulang kapan saja hanya dengan satu command.

6.1 — Buat Migration Wisata
Command untuk membuat file migration:
php artisan make:migration create_wisata_table

Lokasi File:
database/migrations/YYYY_MM_DD_HHMMSS_create_wisata_table.php

Buka file migration tersebut dan ubah isinya menjadi:
<?php

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    public function up(): void
    {
        Schema::create('wisata', function (Blueprint $table) {
            $table->id();
            $table->string('nama_wisata', 100);
            $table->string('kategori', 50);
            $table->string('alamat', 200)->nullable();
            $table->text('deskripsi')->nullable();
            $table->decimal('latitude', 10, 8);
            $table->decimal('longitude', 11, 8);
            $table->string('foto')->nullable();
            $table->timestamps();
        });
    }

    public function down(): void
    {
        Schema::dropIfExists('wisata');
    }
};

6.2 — Buat Migration Mitigasi
php artisan make:migration create_mitigasi_table

Buka file migration mitigasi dan ubah menjadi:
<?php

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    public function up(): void
    {
        Schema::create('mitigasi', function (Blueprint $table) {
            $table->id();
            $table->string('nama_lokasi', 100);
            $table->string('kategori', 50);
            $table->string('alamat', 200)->nullable();
            $table->decimal('latitude', 10, 8);
            $table->decimal('longitude', 11, 8);
            $table->timestamps();
        });
    }

    public function down(): void
    {
        Schema::dropIfExists('mitigasi');
    }
};

6.3 — Buat Migration Admin/Users
Untuk fitur login admin, buat tabel users (Laravel sudah menyediakan migration default):
# Cek apakah migration users sudah ada:
ls database/migrations/

# Jika sudah ada 0001_01_01_000000_create_users_table.php, skip langkah ini
# Jika belum, buat dengan:
php artisan make:migration create_users_table

✅ Hasil yang Diharapkan
File migration wisata berhasil dibuat di database/migrations/
File migration mitigasi berhasil dibuat di database/migrations/
Periksa isi file dengan VS Code, pastikan tidak ada typo

<?php

namespace App\Http\Controllers;

use App\Models\Wisata;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Storage;

class WisataController extends Controller
{
    // Tampilkan daftar wisata (untuk admin)
    public function index()
    {
        $wisata = Wisata::all();
        return view('admin.wisata.index', compact('wisata'));
    }

    // Form tambah wisata
    public function create()
    {
        return view('admin.wisata.create');
    }

    // Simpan wisata baru ke database
    public function store(Request $request)
    {
        $request->validate([
            'nama_wisata' => 'required|max:100',
            'kategori'    => 'required|max:50',
            'alamat'      => 'nullable|max:200',
            'deskripsi'   => 'nullable',
            'latitude'    => 'required|numeric',
            'longitude'   => 'required|numeric',
            'foto'        => 'nullable|image|mimes:jpg,jpeg,png|max:2048',
        ]);

        $data = $request->except('foto');

        if ($request->hasFile('foto')) {
            $data['foto'] = $request->file('foto')
                ->store('wisata', 'public');
        }

        Wisata::create($data);

        return redirect()->route('admin.wisata.index')
            ->with('success', 'Data wisata berhasil ditambahkan!');
    }

    // Form edit wisata
    public function edit(Wisata $wisata)
    {
        return view('admin.wisata.edit', compact('wisata'));
    }

    // Simpan perubahan wisata
    public function update(Request $request, Wisata $wisata)
    {
        $request->validate([
            'nama_wisata' => 'required|max:100',
            'kategori'    => 'required|max:50',
            'latitude'    => 'required|numeric',
            'longitude'   => 'required|numeric',
            'foto'        => 'nullable|image|mimes:jpg,jpeg,png|max:2048',
        ]);

        $data = $request->except(['foto', '_method', '_token']);

        if ($request->hasFile('foto')) {
            if ($wisata->foto) {
                Storage::disk('public')->delete($wisata->foto);
            }
            $data['foto'] = $request->file('foto')
                ->store('wisata', 'public');
        }

        $wisata->update($data);

        return redirect()->route('admin.wisata.index')
            ->with('success', 'Data wisata berhasil diperbarui!');
    }

    // Hapus wisata
    public function destroy(Wisata $wisata)
    {
        if ($wisata->foto) {
            Storage::disk('public')->delete($wisata->foto);
        }
        $wisata->delete();

        return redirect()->route('admin.wisata.index')
            ->with('success', 'Data wisata berhasil dihapus!');
    }

    // API: Return JSON untuk Leaflet
    public function apiIndex()
    {
        return response()->json(Wisata::all());
    }
}

10.1 — Simpan File GeoJSON

# Salin file GeoJSON ke folder tersebut:
# - wisata.geojson   → storage/app/public/geojson/wisata.geojson
# - mitigasi.geojson → storage/app/public/geojson/mitigasi.geojson

10.2 — Buat Artisan Command untuk Import
php artisan make:command ImportGeoJSON

Lokasi File: app/Console/Commands/ImportGeoJSON.php
<?php

namespace App\Console\Commands;

use Illuminate\Console\Command;
use App\Models\Wisata;
use App\Models\Mitigasi;
use Illuminate\Support\Facades\Storage;

class ImportGeoJSON extends Command
{
    protected $signature   = 'import:geojson';
    protected $description = 'Import GeoJSON wisata dan mitigasi ke database';

    public function handle()
    {
        // === IMPORT WISATA ===
        $this->info('Importing wisata...');

        $path    = storage_path('app/public/geojson/wisata.geojson');
        $content = file_get_contents($path);
        $geojson = json_decode($content, true);

        $count = 0;
        foreach ($geojson['features'] as $feature) {
            $props = $feature['properties'];
            $coords = $feature['geometry']['coordinates'];

            Wisata::updateOrCreate(
                ['nama_wisata' => $props['nama_wisata']],
                [
                    'nama_wisata' => $props['nama_wisata'] ?? '',
                    'kategori'    => $props['kategori']    ?? '',
                    'alamat'      => $props['alamat']      ?? '',
                    'deskripsi'   => $props['deskripsi']   ?? '',
                    'longitude'   => $coords[0],
                    'latitude'    => $coords[1],
                    'foto'        => $props['foto']        ?? null,
                ]
            );
            $count++;
        }
        $this->info("Imported {$count} wisata records.");

        // === IMPORT MITIGASI ===
        $this->info('Importing mitigasi...');

        $path    = storage_path('app/public/geojson/mitigasi.geojson');
        $content = file_get_contents($path);
        $geojson = json_decode($content, true);

        $count = 0;
        foreach ($geojson['features'] as $feature) {
            $props = $feature['properties'];
            $coords = $feature['geometry']['coordinates'];

            Mitigasi::updateOrCreate(
                ['nama_lokasi' => $props['nama_lokasi']],
                [
                    'nama_lokasi' => $props['nama_lokasi'] ?? '',
                    'kategori'    => $props['kategori']    ?? '',
                    'alamat'      => $props['alamat']      ?? '',
                    'longitude'   => $coords[0],
                    'latitude'    => $coords[1],
                ]
            );
            $count++;
        }
        $this->info("Imported {$count} mitigasi records.");
        $this->info('Import selesai!');
    }
}

15.2 — Search API Laravel
Tambahkan method search di WisataController:
// Tambahkan di WisataController.php
public function search(Request $request)
{
    $q = $request->get('q', '');

    $wisata = Wisata::where('nama_wisata', 'like', "%{$q}%")
        ->orWhere('kategori', 'like', "%{$q}%")
        ->orWhere('alamat',   'like', "%{$q}%")
        ->get();

    return response()->json($wisata);
}

Tambahkan route di routes/web.php:
Route::get('/api/wisata/search',   [WisataController::class,   'search']);
Route::get('/api/mitigasi/search', [MitigasiController::class, 'search']);

15.3 — Search Real-time di Peta
// Ganti event listener searchInput dengan versi API:
let searchTimeout;
searchInput.addEventListener('input', function () {
    clearTimeout(searchTimeout);
    const query = this.value.trim();
    searchResults.innerHTML = '';
    if (!query) return;

    searchTimeout = setTimeout(() => {
        // Cari di local data (lebih cepat)
        const matches = allMarkers
            .filter(m => m.nama.toLowerCase().includes(query.toLowerCase()))
            .slice(0, 8);

        matches.forEach(({ marker, nama, tipe }) => {
            const item = document.createElement('a');
            item.href = '#';
            item.className = 'list-group-item list-group-item-action small';
            item.innerHTML = `
                <span class="badge bg-${tipe==='wisata'?'success':'danger'}">${tipe}</span>
                ${nama}`,
            item.onclick = e => {
                e.preventDefault();
                map.flyTo(marker.getLatLng(), 16, { animate: true, duration: 1 });
                setTimeout(() => marker.openPopup(), 1000);
                searchResults.innerHTML = '';
                searchInput.value = nama;
            };
            searchResults.appendChild(item);
        });
    }, 300);
});

// Tutup hasil search jika klik di luar
document.addEventListener('click', e => {
    if (!searchInput.contains(e.target)) searchResults.innerHTML = '';
});

⚠️ Troubleshooting Umum
Peta tidak muncul → Cek koneksi internet (Leaflet tiles dari CDN)
Marker tidak muncul → Buka browser console (F12) → cek error di tab Console
API /api/wisata error 500 → Cek log di storage/logs/laravel.log
Login gagal → Pastikan sudah jalankan php artisan migrate dan buat user via tinker
Foto tidak tampil → Pastikan php artisan storage:link sudah dijalankan
Route not found → Cek routes/web.php dan jalankan php artisan route:list
SQLSTATE error → Pastikan MySQL Laragon running dan konfigurasi .env benar
